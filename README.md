# Bamboo Scrimber Simulator

Terra Chemica — Bamboo Scrimber Simulations (University of Dhaka, MRSDU Material Fest 2.0)

Interactive coupled-physics simulations for "Chemical Densification and Resin Optimization for High-Strength Bamboo Scrimber":

1. Coupled Resin Transport + Cure
2. Hot Press Densification + Steam
3. Strength: Break It!
4. Invisible Cloud: TVOC & Indoor Emissions
5. One-Way Street: Anisotropic Penetration / Droplet Race

Experimental anchors: Zheng et al. 2025, *Industrial Crops & Products* 233, 121450. Model predictions are labelled as such on the page.

## Run

Open `index.html` in a browser, or serve it statically — no build step, no server code.

## Deploy

- Vercel: import this repo, framework preset "Other", no build command, output directory `.`
- Render: Static Site, no build command, publish directory `.`
